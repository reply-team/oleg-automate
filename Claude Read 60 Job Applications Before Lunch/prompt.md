# The prompt from the video

Paste this into a new chat in the Claude desktop app, with the Google Drive and Gmail connectors turned on. Change the
lines marked `[change:]`.

```
Read our job post in the Hiring folder in Google Drive and list the must-haves. Then read every resume in the Applications folder, one by one, and write two lines per person: what matches and what is missing. Put the best matches on a short list in a new Google Doc, with the reasons next to each name. Write invitation emails for them as Gmail drafts, and send nothing.
If you cannot read a file, put that person in maybe and tell me.
Leave the interview time blank. I will fill it in.
```

[change:] «the Hiring folder», «the Applications folder» — your own folder names.
[change:] «the must-haves» — check the list Claude writes back before it reads the resumes (ours: two years in customer
support, good written English, a help desk app, working hours that overlap with ours).
