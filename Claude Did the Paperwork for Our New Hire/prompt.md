# The prompt from the video

Paste this into a new chat in the Claude desktop app, with the Gmail, Google Drive and Google Calendar
connectors turned on. Change the lines marked `[change:]`.

```
Find the newest signed offer in my Gmail and read every reply in that conversation. Write down the person's name, role, manager, start date and personal email. Copy our four first-week files in Google Drive, put the name and start date in each copy, and share the copies with the new person. Book the first-week meetings in Google Calendar, write a welcome email as a Gmail draft, and do not send anything.
If the dates don't match, use the newest one and tell me.
Name each copy with the person's name and start date.
```

[change:] «our four first-week files» — name your own files (ours: First-week checklist, First-week plan, Tax form,
Bank details form).
[change:] «the first-week meetings» — list yours (ours: a welcome call with the manager, a laptop setup, a team lunch on
day two, a first one-on-one on Friday).
