# Deliverables — "One blog post → twelve pieces"

One file this video promises on camera:

> "The file with all twelve formats is in the description. Swap in your platforms."

| file | what it is |
|---|---|
| `12-formats.md` | the promised file — twelve derivative formats, each with the rule the agent follows, the failure mode the review queue checks, and a worked example |
| `example-post.md` | the source article every example is cut from, so the twelve can be checked against the thing they came from |

`12-formats.md` writes `<PLATFORM A>` and `<PLATFORM B>` instead of naming products. The video says
"a short version for one platform, in that platform's tone" and shows neutral icons, so the file
matches: the tone rules are the transferable part, the logos are not. Those two slots are the only
thing you have to edit.

`example-post.md` is a fictional article on a fictional domain, written for this video so the twelve
derivatives could be real text rather than placeholders. It is here because a format file without a
worked example is a list of nouns.
